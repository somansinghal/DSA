DSA LAB — SEPARATE C PROGRAMS

Each .c file is a separate program. Compile and run one file at a time, for example:
gcc 05_linear_search.c -o program
./program

Contents:
01-04 Matrix addition, subtraction, multiplication, transpose
05-06 Linear and binary search
07-10 Insertion, bubble, selection, quick sort
11-13 Stack traversal, push, pop
14-16 Fibonacci, factorial, Tower of Hanoi
17 Merge sort
18-20 Queue insertion, deletion, traversal
21-22 Postfix evaluation, infix-to-postfix
23-25 Linked-list insertion at beginning, end, position
26-28 Linked-list deletion at beginning, end, position
29-30 Doubly linked-list insertion and traversal
31-32 BFS and DFS

Notes:
- Binary search needs a sorted array.
- Graph programs use vertices numbered 0 through n-1 and an adjacency matrix.
- Postfix evaluation supports single-digit operands and +, -, *, /.
- Infix-to-postfix supports single-character operands, parentheses, and +, -, *, /, ^.
- These are beginner-friendly lab implementations. Use valid input sizes and positions.
